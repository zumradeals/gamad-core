# CAP-CORE-018 — Incidents

**État :** `IMPLÉMENTÉ PARTIEL`

## Objectif

Maintenir le cycle des incidents, impacts, actions, preuves et clôtures.

## Code à inspecter

`core/registre-incidents`

## Hors périmètre

La dissimulation d’erreurs, de données personnelles ou de secrets dans le dossier.

## Prochain résultat

Éprouver déclaration, traitement, communication, clôture et retour d’expérience.

Le statut ne change qu’après preuve par le code, les tests, les contrats consommés et, lorsque l’exploitation est revendiquée, les observations et restaurations réelles.
