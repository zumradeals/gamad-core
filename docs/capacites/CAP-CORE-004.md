# CAP-CORE-004 — Autorisation commune

**État :** `OPÉRATIONNEL LIMITÉ`

## Objectif

Décider si un sujet peut effectuer une action sur une ressource dans un contexte donné.

## Code à inspecter

`core/registre-autorisation`

## Hors périmètre

La création d’identité, l’authentification et l’exécution de l’action métier.

## Prochain résultat

Remplacer les politiques dérivées de textes par des politiques techniques explicites et administrables.

Le statut ne change qu’après preuve par le code, les tests, les contrats consommés et, lorsque l’exploitation est revendiquée, les observations et restaurations réelles.
