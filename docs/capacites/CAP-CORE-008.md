# CAP-CORE-008 — Registre des décisions

**État :** `HÉRITÉ À MIGRER`

## Objectif

Conserver les décisions opérationnelles et architecturales qui doivent être retrouvées et expliquées.

## Code à inspecter

`core/registre-decisions`

## Hors périmètre

Un système juridique interne ou une approbation préalable de chaque modification.

## Prochain résultat

Conserver uniquement les décisions d’ingénierie utiles et leur impact observable.

Le statut ne change qu’après preuve par le code, les tests, les contrats consommés et, lorsque l’exploitation est revendiquée, les observations et restaurations réelles.
