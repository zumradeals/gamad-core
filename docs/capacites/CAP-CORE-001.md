# CAP-CORE-001 — Identity Registry

**État :** `OPÉRATIONNEL LIMITÉ`

## Objectif

Maintenir l’identité canonique et continue des personnes, organisations, produits, agents, services et realms reconnus.

## Code à inspecter

`core/registre-identites`

## Hors périmètre

Les profils métier détaillés, les droits, les mots de passe et les scores de pertinence.

## Prochain résultat

Stabiliser les contrats d’identité et préparer la fédération GamaDrive/Wasplex.

Le statut ne change qu’après preuve par le code, les tests, les contrats consommés et, lorsque l’exploitation est revendiquée, les observations et restaurations réelles.
