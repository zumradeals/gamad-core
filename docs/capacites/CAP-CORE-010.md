# CAP-CORE-010 — Lexique commun

**État :** `HÉRITÉ À MIGRER`

## Objectif

Maintenir les termes techniques partagés nécessaires à l’interopérabilité.

## Code à inspecter

`core/registre-lexique`

## Hors périmètre

Une doctrine générale imposée au-delà des termes nécessaires aux contrats.

## Prochain résultat

Réduire le lexique aux termes utilisés par les API, événements et données.

Le statut ne change qu’après preuve par le code, les tests, les contrats consommés et, lorsque l’exploitation est revendiquée, les observations et restaurations réelles.
