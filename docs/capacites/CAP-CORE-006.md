# CAP-CORE-006 — Registre des sources

**État :** `HÉRITÉ À MIGRER`

## Objectif

Identifier les sources techniques ou documentaires, leur provenance et leur authenticité.

## Code à inspecter

`core/registre-sources`

## Hors périmètre

Le contenu métier complet des sources et une hiérarchie juridique des textes.

## Prochain résultat

Transformer le registre documentaire en catalogue technique de provenance réellement consommé.

Le statut ne change qu’après preuve par le code, les tests, les contrats consommés et, lorsque l’exploitation est revendiquée, les observations et restaurations réelles.
