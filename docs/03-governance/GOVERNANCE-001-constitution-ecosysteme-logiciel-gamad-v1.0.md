# GOVERNANCE-001 — Constitution de l'Écosystème Logiciel GAMAD

Version 1.0

Ce document établit la gouvernance normative de l'écosystème logiciel GAMAD.

## Principes
- Primauté du Livre Blanc.
- Primauté de la Charte Fondatrice.
- Primauté du GAMAD Core.
- Primauté des contrats explicites.

## Autorités
- Fondateur
- Orchestrateur
- Architecte
- Mainteneurs
- Développeurs
- Contributeurs

## Hiérarchie documentaire
Livre Blanc → Charte Fondatrice → Charte Identitaire → Constitution → Core Charter → Lois → Lexique → ADR → Atlas → Modèle Conceptuel → Cahiers des charges.

## Cycle de décision
Vision → ADR → Validation → Conception → Implémentation → Tests → Publication → Maintenance.

## Règle fondamentale
Aucune implémentation structurante ne peut contourner cette gouvernance.
