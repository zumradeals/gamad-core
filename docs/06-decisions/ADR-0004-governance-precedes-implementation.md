# ADR-0004 — Governance precedes implementation

**Statut :** Accepté

## Décision

Toute évolution touchant aux fondations de GAMAD doit suivre une gouvernance explicite avant toute implémentation.

## Règles
1. Toute modification structurelle passe par une ADR.
2. Les documents fondateurs priment sur le code.
3. Les contrats sont définis avant les API.
4. Les concepts sont définis avant les modèles de données.
5. Les responsabilités sont établies avant les implémentations.

## Formule canonique
> La gouvernance précède l'implémentation. L'architecture précède le code.
