## 1. Objet de la Charte

La présente Charte protège l’identité symbolique, institutionnelle et visuelle de GAMAD.

Elle fixe :

- l’origine du nom ;
- la mission fondatrice ;
- la devise ;
- le slogan ;
- le rôle du Père fondateur ;
- la portée symbolique du logo ;
- les couleurs fondatrices ;
- les règles d’usage de la marque ;
- la distinction entre GAMAD, ses institutions, ses branches, ses produits et ses systèmes numériques ;
- les principes qui devront guider toute évolution future de l’identité visuelle.

Cette Charte ne constitue ni un document marketing ni une simple charte graphique. Elle protège un patrimoine.

---

## 2. Origine fondatrice

GAMAD est né en 2019 à l’initiative du Cheikh Gaoussou Dramé.

Le mouvement a été conçu comme une organisation sociale et religieuse orientée vers :

- le développement durable ;
- la solidarité internationale ;
- l’éducation ;
- la formation ;
- le travail ;
- l’adoration ;
- la paix ;
- la justice ;
- la charité ;
- la connaissance mutuelle ;
- le dialogue ;
- la création d’activités économiques et sociales utiles.

L’identité numérique contemporaine de GAMAD ne crée pas cette vocation. Elle la prolonge.

---

## 3. Nom développé

La forme canonique proposée est :

> **Globales Activités et Mouvements en Action pour le Développement**

Les documents historiques présentent plusieurs variantes rédactionnelles, notamment autour de :

- « Mouvement » ou « Mouvements » ;
- « Action » ou « Actions » ;
- « Globales Activités » ou « Global Activités ».

Ces variantes doivent être conservées comme traces historiques.

Aucune normalisation définitive ne devra effacer les formulations originales. Toute forme canonique future devra être validée par l’autorité compétente de GAMAD.

---

## 4. Définition institutionnelle

GAMAD est une réalité globale, sociale, religieuse, communautaire, économique, éducative et institutionnelle.

Il ne doit pas être réduit :

- à une application ;
- à une entreprise ;
- à un mouvement numérique ;
- à une marque commerciale ;
- à un logiciel ;
- à une plateforme technique.

Les produits, entreprises, applications, branches et services portant le nom GAMAD sont des manifestations partielles de cette réalité plus vaste.

> **GAMAD est Tout. Mais tout n’est pas GAMAD.**

Cette formule exprime une limite : le nom peut embrasser de nombreux domaines, mais son usage ne doit jamais être banal, arbitraire ou incohérent avec les principes fondateurs.

---

## 5. Père fondateur

Le Cheikh Gaoussou Dramé est reconnu comme Père fondateur de GAMAD.

Son rôle fondateur ne peut être effacé par :

- une évolution technologique ;
- une restructuration institutionnelle ;
- une transformation commerciale ;
- une nouvelle branche ;
- une modernisation graphique.

Toute documentation historique ou institutionnelle majeure relative à GAMAD doit préserver cette filiation.

---

## 6. Slogan fondateur

Le slogan fondateur est :

> **Vivre la religion de Dieu pour chaque mouvement religieux.**

Ce slogan appartient à l’identité doctrinale et institutionnelle.

Il ne doit pas être confondu avec :

- une promesse produit ;
- une accroche commerciale ;
- un slogan temporaire de campagne ;
- une proposition de valeur technique.

Des produits GAMAD peuvent disposer de leurs propres signatures commerciales, à condition qu’elles ne remplacent pas le slogan fondateur et ne le contredisent pas.

---

## 7. Devise

La devise officielle est :

> **Formation – Travail – Adoration**

Elle exprime une progression fondamentale :

1. **Formation** — acquérir la connaissance, la discipline et la capacité ;
2. **Travail** — transformer la connaissance en action utile ;
3. **Adoration** — inscrire l’action humaine dans une finalité spirituelle supérieure.

La devise doit être conservée dans les documents institutionnels, cérémoniels, éducatifs et fondateurs.

Son usage commercial doit rester mesuré et respectueux.

## 9. Les trois niveaux d’identité

### 9.1 GAMAD institutionnel

Il représente la réalité fondatrice, historique, doctrinale et organisationnelle.

### 9.2 GAMAD public

Il représente les branches, institutions, entreprises, programmes, produits et services visibles.

### 9.3 GAMAD numérique

Il représente le Core, le Hub, les applications, les API, les infrastructures et les systèmes techniques.

Le niveau numérique sert GAMAD. Il ne définit pas à lui seul GAMAD.

> **Le GAMAD Core est le noyau souverain de l’écosystème numérique GAMAD. Il n’est ni le noyau doctrinal, ni le noyau spirituel, ni l’autorité institutionnelle suprême de GAMAD tout entier.**

## 10. Logo fondateur

Le logo officiel historique de GAMAD est composé de :

- deux mains ouvertes ;
- un globe terrestre centré sur l’Afrique ;
- un soleil ;
- un croissant de lune ;
- un arc d’étoiles ;
- une base jaune portant le nom GAMAD et son écriture arabe.

Ce logo est classé comme **logo fondateur patrimonial**.

Il doit être :

- conservé dans sa version originale ;
- archivé dans les sources officielles ;
- protégé contre les modifications arbitraires ;
- distingué d’éventuelles versions modernisées.

Une modernisation future ne doit jamais entraîner la disparition de l’original.

- la nuit ;
- le temps ;

Les étoiles expriment :

- l’orientation ;

## 12. Couleurs fondatrices

Les couleurs fondatrices observées dans le logo sont :

- jaune ;
- bleu ;
- vert ;
- blanc ;
- noir.

Leur signification institutionnelle proposée est :

| Couleur | Signification fondatrice |
|---|---|
| Jaune | lumière, espérance, générosité, énergie |
| Bleu | confiance, calme, connaissance, ouverture |
| Vert | vie, croissance, développement, équilibre |

Les valeurs numériques exactes — HEX, RGB, CMYK et références d’impression — devront être définies dans un futur document technique de design après extraction et validation professionnelle.

Aucune valeur approximative ne doit être déclarée comme officielle avant cette validation.

## 13. Typographie

Aucune typographie officielle définitive n’est encore fixée par la présente Charte.

La future sélection devra respecter :

- la lisibilité ;
- la disponibilité durable ;
- la compatibilité multilingue ;
- la prise en charge du français, de l’arabe et des usages internationaux ;
- la sobriété institutionnelle ;
- la distinction claire entre identité institutionnelle et interfaces numériques.

La typographie choisie ne doit pas devenir une dépendance impossible à remplacer.

## 14. Architecture de marque

La forme recommandée est :

```text
GAMAD
├── GAMAD Drive
├── GAMAD Docs
├── GAMAD Mail
├── GAMAD Copilote
├── GAMAD Santé
├── GAMAD Transport
└── autres branches validées
```

Règles :

1. GAMAD est la marque mère.
2. Le second terme indique la branche, le produit ou le service.
3. Une branche ne doit pas présenter son identité comme supérieure à GAMAD.
4. Les systèmes internes tels que Core, Hub ou Identity Service ne doivent pas être traités automatiquement comme des marques commerciales.
5. Une sous-marque doit posséder un responsable, un périmètre et un contrat d’usage du nom.

---

## 15. Usages autorisés

Le nom et les symboles GAMAD peuvent être utilisés pour :

- les activités institutionnelles ;
- les documents officiels ;
- les branches approuvées ;
- les programmes éducatifs et sociaux ;
- les produits numériques validés ;
- les entreprises ou structures autorisées ;
- les événements officiels ;
- les supports de communication approuvés.

---

## 16. Usages interdits

Sont interdits sans autorisation :

- créer une branche portant le nom GAMAD ;
- modifier le logo fondateur ;
- retirer un symbole historique pour des raisons de mode ;
- utiliser GAMAD pour une activité contraire à ses principes ;
- présenter un produit privé comme représentant tout GAMAD ;
- utiliser le nom pour tromper, collecter des fonds ou obtenir une autorité non accordée ;
- réduire GAMAD à une simple marque commerciale ;
- employer la devise ou le slogan de manière irrespectueuse ;
- confondre le Core numérique avec l’autorité institutionnelle ou spirituelle globale.

---

## 17. Modernisation graphique

Une modernisation est possible si elle répond à un besoin démontré.

Elle doit respecter les conditions suivantes :

1. conserver le logo fondateur dans les archives ;
2. documenter chaque modification ;
3. préserver les symboles essentiels ou justifier formellement toute évolution ;
4. produire une version institutionnelle, une version simplifiée et des variantes numériques cohérentes ;
5. éviter les effets de mode difficiles à maintenir ;
6. garantir la lisibilité en petit format, en monochrome et sur différents supports ;
7. être validée par l’autorité institutionnelle compétente.

Une modernisation ne constitue pas une réécriture de l’histoire.

## 19. Gouvernance identitaire

Toute évolution de l’identité doit préciser :

- l’autorité qui la propose ;
- la raison du changement ;
- les éléments concernés ;
- les conséquences symboliques ;
- les supports affectés ;
- la stratégie de migration ;
- les versions conservées ;
- la date d’entrée en vigueur.

Aucun changement silencieux n’est autorisé.

---

## 20. Conservation patrimoniale

Doivent être conservés durablement :

- le premier logo officiel ;
- les premières versions des statuts ;
- les documents rédigés sous la dictée du Père fondateur ;
- les premières affiches, entêtes et signatures ;
- les anciennes variantes du nom ;
- les versions successives de la présente Charte ;
- les décisions expliquant les évolutions de l’identité.

Le patrimoine historique ne doit jamais être écrasé par les versions récentes.

---

## 21. Déclaration finale

GAMAD possède une identité antérieure à ses produits numériques.

Ses applications pourront changer.

Ses branches pourront se multiplier.

Ses interfaces pourront évoluer.

Mais son origine, sa devise, sa filiation, sa mission et ses symboles fondateurs devront rester reconnaissables.

> **Formation – Travail – Adoration**

> **Vivre la religion de Dieu pour chaque mouvement religieux.**

L’identité de GAMAD n’est pas un habillage.

Elle est une mémoire, une responsabilité et une transmission.
